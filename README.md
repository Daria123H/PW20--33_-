# Git Lab

## Опис проєкту

Цей проєкт створено для виконання лабораторної роботи
з вивчення системи контролю версій Git.

## Мета проєкту

Ознайомитися з основними можливостями Git:
- створення локального репозиторію;
- створення комітів;
- робота з гілками;
- злиття гілок;
- вирішення конфліктів;
- використання rebase;
- створення тегів;
- документування змін у проєкті.

## Технології

- Git
- Git Bash
- GitHub
